## 二、项目目标

本项目开发一个人工智能应用系统，实现：

| 维度 | 说明 |
|------|------|
| **输入** | 用户在画板中手写 0–9 数字，或上传一张手写数字图片。 |
| **功能** | 使用**优化后的**卷积神经网络（CNN）对输入图像进行预处理与推理，输出最可能的数字及各类别概率。 |
| **输出** | 识别结果（预测数字）、0–9 各类别概率（如前 3 名展示），以及必要的提示信息（如“请重新绘制”）。 |
| **交互方式** | 通过浏览器访问本地/部署的 Gradio Web 界面：画板书写、清空、提交识别，结果在页面右侧实时展示。 |

**最终目标**：在现有可运行系统基础上，完成**训练流程修正与模型结构优化**、健壮性增强与前端美化，形成可完整运行、便于演示和答辩的 AI 应用系统，并**体现明确的算法与代码工作量**。

## 三、系统主要功能

### 1. 数据输入功能

- **画板输入**：在 Web 界面画板中手写 0–9 数字，支持清空重画。
- **图片上传**（可选扩展）：支持用户上传本地手写数字图片进行识别。
- **输入校验**：对空白或无效输入进行检测并给出友好提示（如“请先书写数字”）。

### 2. AI 分析功能（含模型优化）

- **图像预处理**：将画板/上传图像转为灰度、缩放到 28×28、归一化，并与 MNIST 分布一致（如反色、数值范围 [0,1]）。
- **模型推理**：加载**优化后**的 CNN 模型（如 `cnn_model_v3.h5`），对预处理后的图像进行前向推理。
- **结果解析**：对模型输出做 softmax 得到 0–9 概率分布，取前若干名或最高置信度结果；低置信度时给出“请重新尝试”等提示。

### 3. 结果展示功能

- **识别结果展示**：展示预测数字及对应概率（如条形图或标签形式）。
- **前 K 名展示**：例如展示概率最高的前 3 个数字及其置信度，便于用户理解模型判断。

### 4. 算法与模型优化（核心工作量体现）

本部分通过**训练流程修正**与**模型结构升级**体现主要代码与实验工作量：

| 优化项 | 内容说明 | 代码/产出 |
|--------|----------|-----------|
| **① 验证集与数据流修正** | 使用 `train_test_split` 得到的 `x_train_split`、`y_train_split` 做 `datagen.flow` 与训练，使用 `(x_val, y_val)` 仅做验证，避免数据泄露、保证验证指标可信。 | 修改 `CNN_Model_Training.ipynb` 中数据划分与 `fit()` 的 `datagen.flow` 入参；补充说明性注释与运行结果记录。 |
| **② 模型结构优化** | 在现有 3 层卷积（32→64→128）基础上，**新增一层卷积**：Conv2D(256, (3,3)) + BatchNormalization + Dropout(0.25)，再 Flatten 接全连接与输出层，提升表达与泛化能力。 | 在 notebook 中新增/修改模型构建代码块；`model.summary()` 与结构说明；参数量与层数对比（可选表格）。 |
| **③ 训练流程完善** | 引入 EarlyStopping、ModelCheckpoint（按 `val_accuracy` 保存最佳权重）、ReduceLROnPlateau 等回调；固定随机种子保证可复现。 | 新增回调与 `fit(callbacks=[...])` 代码；保存最佳模型为 `cnn_model_v3.h5`；训练曲线（loss/accuracy）可视化。 |
| **④ 评估与可解释性** | 在测试集上评估最终指标；绘制混淆矩阵；选取若干错例进行“原图 + 真实标签 + 预测标签”可视化，用于分析与报告。 | 新增评估代码块、混淆矩阵绘图、错例展示代码；在报告/PPT 中引用图表并分析易混淆数字（如 4/9、3/8）。 |
| **⑤ 与应用的衔接** | 将 `app.py` 中模型路径改为加载 `cnn_model_v3.h5`，确认预处理与训练阶段一致，并做端到端测试。 | 修改 `app.py` 一行；在 README 或计划中注明“使用 v3 模型”及改进点摘要。 |

上述 ①～⑤ 贯穿**数据管线 → 模型定义 → 训练配置 → 评估与可视化 → 应用集成**，形成完整、可展示的算法优化闭环，便于在报告与答辩中体现**大量代码与实验工作量**。

### 5. 简单统计或记录功能（可选扩展）

- **单次会话统计**：当次使用中的识别次数、平均置信度等。
- **历史记录**：在当次会话内保留最近若干次“输入—预测结果”，便于对比与演示（可不持久化，仅内存）。

### 6. 其他功能（优化方向）

- **异常与健壮性**：模型文件缺失、路径错误、推理异常时的友好提示与日志；输入格式异常时的防护。
- **界面与体验**：中文界面、布局优化、主题统一、响应式与提示文案优化，便于答辩演示。

## 附录：算法优化与工作量说明

- **优化思路**：  
  - **训练数据与验证**：用 `x_train_split`、`y_train_split` 做 `datagen.flow` 和训练，用 `(x_val, y_val)` 做验证，保证验证集独立、指标可信。  
  - **模型结构**：在原有 3 层卷积基础上增加一层（Conv2D 256 + BatchNormalization + Dropout），再 Flatten 接全连接与输出，形成“4 层卷积 + 全连接”的升级版 CNN，便于在报告中体现结构设计与调参工作量。

- **可体现的代码与实验工作量**：  
  - 数据管线修改（划分、`flow` 入参、注释）；  
  - 模型构建代码修改/新增（新卷积层、BN、Dropout）；  
  - 训练配置（回调、随机种子、保存路径）；  
  - 评估与可视化（评估代码、混淆矩阵、错例图）；  
  - 与 `app.py` 的衔接与测试；  
  - 实验记录与报告中的改进说明与图表引用。
