# 项目启动与使用指南

本文档面向首次使用本仓库的同学或答辩演示人员，说明环境配置、两条业务线的启动方式及常见问题。

---

## 1. 项目里有两套可运行程序

| 程序 | 入口文件 | 功能简述 | 依赖的模型文件 |
|------|----------|----------|----------------|
| 手写数字识别（画板） | `app.py` | 浏览器中画一个 0–9，CNN 给出概率 | `cnn_model_v2.h5`（与 `app.py` 中路径一致） |
| 模糊验证码登录演示 | `login_captcha_tkinter.py` | 桌面窗口展示 4 位模糊验证码，输入后校验登录 | `captcha_digit_cnn.h5`（需先训练生成） |

两套程序**相互独立**，可按需只配置其中一套。

---

## 2. 环境要求

- **操作系统**：Windows / macOS / Linux 均可；验证码登录界面使用 Tkinter（Python 标准库，Windows 自带）。
- **Python**：建议 **3.10** 或 **3.11**（与 TensorFlow 2.12+ 兼容）。
- **网络**：首次构建验证码数据集时需下载 MNIST（见下文「数据下载失败」）。

---

## 3. 通用准备步骤（只需做一次）

### 3.1 进入项目根目录

在终端（Windows 可用 PowerShell）中执行（请把路径改成你本机实际路径）：

```powershell
cd "你的路径\Hand-Written-Digit-Recognition-main"
```

### 3.2 （推荐）虚拟环境

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

若提示无法执行脚本，可先执行：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 3.3 安装依赖

```powershell
pip install -r requirements.txt
```

依赖说明见仓库根目录下的 `requirements.txt`（含 TensorFlow、Gradio、SciPy、scikit-learn、Pillow 等）。

---

## 4. 启动「手写数字识别」（Gradio Web）

### 4.1 准备模型

确认项目根目录存在 **`cnn_model_v2.h5`**。若仓库未附带该文件，需要：

- 使用 `CNN_Model_Training.ipynb` 训练并导出同名模型，或  
- 修改 `app.py` 第 6 行，将 `load_model("cnn_model_v2.h5")` 改为你本地的 `.h5` 路径。

### 4.2 启动

```powershell
python app.py
```

终端会打印本地地址（一般为 **http://127.0.0.1:7860**），用浏览器打开即可：在画板书写数字 → 点击「识别数字」查看预测与概率。

### 4.3 停止

在运行 `app.py` 的终端中按 **Ctrl+C**。

---

## 5. 启动「模糊验证码登录」（Tkinter）

### 5.1 首次使用：生成数据并训练（顺序固定）

在项目根目录依次执行：

```powershell
python data\build_captcha_dataset.py
python train_captcha_cnn.py
```

成功后根目录应出现 **`captcha_digit_cnn.h5`**，`data` 目录下应有 **`captcha_dataset.npz`**。

说明：

- `build_captcha_dataset.py` 默认会生成较大规模数据，训练时间取决于 CPU/GPU；也可用参数减小样本做快速试验，例如：  
  `python data\build_captcha_dataset.py --n-train 800 --n-test 200`  
- `train_captcha_cnn.py` 会读取上述 `npz` 并保存 `captcha_digit_cnn.h5`。

### 5.2 启动登录界面

```powershell
python login_captcha_tkinter.py
```

操作说明：

- 在输入框中输入图中 **从左到右 4 位数字**，点击「登录」。  
- **默认校验规则**：输入与「图像内真实 4 位」一致则登录成功（与常见网站服务端存答案一致）；界面会显示 CNN 识别结果供参考。  
- 登录失败会弹窗提示，并 **自动刷新** 新验证码。  
- 「换一张」可手动换新验证码。

### 5.3 可选：改为「必须与 CNN 输出一致」

在**同一终端**先设置环境变量再启动（PowerShell）：

```powershell
$env:CAPTCHA_VERIFY="model"
python login_captcha_tkinter.py
```

此模式下需保证模型已用足量数据训练好，否则容易误判。

### 5.4 停止

关闭窗口或在终端 **Ctrl+C**。

---

## 6. 可选：仅下载 MNIST 压缩包到本地

若自动下载不稳定，可将 Keras 格式的 **`mnist.npz`** 放到项目根目录；或通过环境变量指定路径：

```powershell
$env:MNIST_NPZ_PATH="D:\datasets\mnist.npz"
python data\build_captcha_dataset.py
```

也可运行辅助脚本（需网络）：

```powershell
python data\fetch_mnist_npz.py
```

## 7. 常见问题

| 现象 | 可能原因 | 处理建议 |
|------|----------|----------|
| `app.py` 报错找不到 `cnn_model_v2.h5` | 模型未放入根目录 | 补全模型或修改 `app.py` 加载路径 |
| `build_captcha_dataset` 长时间无输出 | 正在下载 MNIST | 等待；或配置 OpenML/本地 `mnist.npz`（见第 6 节） |
| `login_captcha_tkinter.py` 提示缺少 `captcha_digit_cnn.h5` | 未训练 | 先完成第 5.1 节两步 |
| Tkinter 界面中文乱码 | 系统字体/编码 | 可尝试安装「微软雅黑」或改用英文系统区域测试 |
| TensorFlow GPU 在 Windows 上不可用 | TF ≥ 2.11 官方限制 | 使用 CPU 即可；或查阅 TensorFlow 文档使用 WSL2 |
